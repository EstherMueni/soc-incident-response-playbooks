# SOC Incident Response Playbooks

Standard operating procedures for Tier 1 SOC analysts 
covering the three most common security incidents 
encountered in enterprise environments.

## Playbooks

| Playbook | Incident Type | Severity |
|---|---|---|
| [Playbook 01](playbook-01-brute-force.md) | Brute Force Attack | HIGH |
| [Playbook 02](playbook-02-phishing.md) | Phishing Email | MEDIUM to HIGH |
| [Playbook 03](playbook-03-malware.md) | Malware Detection | LOW to CRITICAL |

## Framework
All playbooks follow NIST SP 800-61 incident response 
methodology across six phases:

1. Preparation
2. Detection & Analysis
3. Containment
4. Eradication
5. Recovery
6. Lessons Learned

## Skills Demonstrated
- SOC Tier 1 incident response workflow
- Alert triage and true positive identification
- Threat intelligence enrichment methodology
- Escalation decision making
- MITRE ATT&CK framework mapping
- Professional SOC documentation
- NIST incident response methodology
